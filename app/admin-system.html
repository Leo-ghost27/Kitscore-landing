Signup / connection health check

Escrow stuck-contract nudge
Nudges any sponsor sitting on a submitted deliverable 5+ days without releasing or disputing, and sends one digest to admin. Runs daily at 10:00 UTC.
Table permissions check
Catches a specific, recurring bug: a table with a correct row-level security policy but no table-level grant at all -- Postgres blocks every request before RLS is even evaluated, and it only ever surfaced by accident (someone clicking into a broken admin page). Run this any time a new table ships, or if a page says "permission denied."
Scan all tables for missing grants
Lists any table that has an RLS policy but isn't actually reachable by a logged-in user.
